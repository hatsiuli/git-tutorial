Τα 4 Βασικά Στάδια Αρχείων
Untracked (Μη παρακολουθούμενο): Νέα αρχεία που δεν έχουν προστεθεί ακόμα στο Git.
Modified (Τροποποιημένο): Αρχεία που αλλάξατε, αλλά δεν έχετε αποθηκεύσει ακόμα στο Git.
Staged (Προετοιμασμένο): Αρχεία που σημαδέψατε ως έτοιμα για να μπουν στο επόμενο commit.
Committed (Καταχωρημένο): Αρχεία που αποθηκεύτηκαν με ασφάλεια στην τοπική σας βάση δεδομένων.

Οι "φάκελοι" του git
Working Directory (Κατάλογος Εργασίας): Εδώ τροποποιείτε τα αρχεία στον υπολογιστή σας.
Staging Area (Περιοχή Προετοιμασίας): Χρησιμοποιείτε την εντολή git add για να μεταφέρετε τις αλλαγές εδώ.
Local Repository (Τοπικό Αποθετήριο): Χρησιμοποιείτε την εντολή git commit για να κλειδώσετε τις αλλαγές στο ιστορικό σας.
Remote Repository (Απομακρυσμένο Αποθετήριο): Χρησιμοποιείτε την εντολή git push για να στείλετε τις αλλαγές σε πλατφόρμες όπως το GitHub ή το GitLab.

Οι 4 Κύριες Εντολές Ροής
git add: Προετοιμάζει τις αλλαγές σας. Μεταφέρει αρχεία από τον Κατάλογο Εργασίας (Working Directory) στην Περιοχή Προετοιμασίας (Staging Area).
git commit -m "μήνυμα": Αποθηκεύει οριστικά τις αλλαγές. Δημιουργεί ένα «στιγμιότυπο» (snapshot) του κώδικα στο Τοπικό Αποθετήριο (Local Repository).
git push: Ανεβάζει τα commits σας. Μεταφέρει την τοπική σας εργασία στο Απομακρυσμένο Αποθετήριο (Remote Repository, π.χ. GitHub).
git pull: Κατεβάζει και συγχωνεύει. Φέρνει τις τελευταίες αλλαγές από το απομακρυσμένο αποθετήριο στον υπολογιστή σας.

Συμπληρωματικές Εντολές Ελέγχουgit 
init: Δημιουργεί ένα νέο, άδειο τοπικό αποθετήριο Git σε έναν φάκελο.
git clone <url>: Αντιγράφει ένα ήδη υπάρχον απομακρυσμένο project στον υπολογιστή σας.
git status: Δείχνει την κατάσταση των αρχείων (ποια είναι τροποποιημένα, ποια έτοιμα για commit).
git log: Εμφανίζει το ιστορικό όλων των commits που έχουν γίνει στο project.

Η git branch δημιουργεί έναν ανεξάρτητο χώρο εργασίας μέσα στο ίδιο project.
Απομόνωση: Σας επιτρέπει να γράφετε νέα χαρακτηριστικά (features) χωρίς να χαλάτε τον κεντρικό, λειτουργικό κώδικα (συνήθως main ή master).
Παράλληλη εργασία: Πολλά άτομα μπορούν να δουλεύουν ταυτόχρονα σε διαφορετικά branches χωρίς να ενοχλεί το ένα το άλλο.
Συγχώνευση: Όταν το νέο χαρακτηριστικό είναι έτοιμο και δοκιμασμένο, το branch συγχωνεύεται (git merge) πίσω στον κεντρικό κώδικα.

Η εντολή git checkout χρησιμεύει κυρίως για να πλοηγείστε μεταξύ διαφορετικών branches ή για να επαναφέρετε αρχεία στην προηγούμενη κατάστασή τους.
